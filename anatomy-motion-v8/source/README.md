# Blender 3D motion v8

Эти шесть MP4 используются на сайте и рендерятся в
Blender из одной объёмной женской манекен-модели, одного Armature, одной
перспективной камеры и неизменного света. Никаких AI-кадров, morph targets или
оптической интерполяции нет.

Сборка:

```powershell
blender.exe --background --python build_and_render.py
```

Исходная сцена: `female-anatomy-rig.blend`. Готовые MP4 и WebP-постеры лежат
на уровень выше, в `anatomy-motion-v8`. Параметры роликов: 640×640, 30 fps,
96 кадров, H.264, 3,2 с. Ключи Bezier Auto Clamped.

Тайминг Blender 1–96 соответствует спецификации 0–95: старт 1–9, движение
10–41, конец 42–56, возврат 57–88, старт 89–96.
