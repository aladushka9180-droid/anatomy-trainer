# PrimeTime Pro для Android: недавние входящие

Небольшая Android-оболочка открывает рабочий кабинет PrimeTime Pro и, только по нажатию пользователя, предлагает выбрать номер из недавних входящих или пропущенных звонков.

## Приватность и границы

- Доступ запрашивается после отдельного понятного объяснения и системного подтверждения Android.
- Приложение читает журнал только при открытии списка, не работает с ним в фоне и не выгружает список на сервер.
- В веб-форму передаётся только выбранный пользователем номер. В CRM он попадёт лишь после обычного создания записи.
- JavaScript-мост не отдаёт веб-странице весь журнал и работает только когда открыт точный production-раздел PrimeTime Pro.
- `READ_CALL_LOG` — ограниченное разрешение Android. Эта сборка предназначена для личной установки через ADB, а не для публикации в Google Play.

## Сборка

Требуются JDK 17, Android SDK 35 и Gradle 8.10.2:

```text
gradle testDebugUnitTest lintDebug assembleDebug
```

Готовый APK: `app/build/outputs/apk/debug/app-debug.apk`.

## Установка

Подключить Android-телефон с включённой отладкой по USB и выполнить:

```text
adb install -r -g app-debug.apk
```

После запуска открыть «Новую запись», нажать «Звонки» возле телефона и подтвердить доступ в системном окне Android. Если производитель телефона дополнительно блокирует ограниченное разрешение, его нужно разрешить вручную в настройках приложения.
