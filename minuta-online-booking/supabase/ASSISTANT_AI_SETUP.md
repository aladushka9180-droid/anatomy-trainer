# Защищённый ИИ-разбор команд

`assistant-understand` — необязательное серверное усиление операционного помощника «Минута». Локальный разбор остаётся основным быстрым контуром, а Edge Function подключается только для неоднозначных, длинных или контекстных фраз.

## Секреты

Ключ OpenAI и имя разрешённой модели должны храниться только в Supabase Secrets. Их нельзя добавлять в `config.js`, HTML, Service Worker, GitHub Pages или репозиторий.

```bash
supabase secrets set OPENAI_API_KEY=... OPENAI_MODEL=...
```

Для дополнительного сайта или локального стенда укажите точные origins через запятую:

```bash
supabase secrets set ASSISTANT_ALLOWED_ORIGINS=https://example.ru,http://127.0.0.1:5500
```

Производственный GitHub Pages origin уже включён в серверный белый список.

## Публикация функции

```bash
supabase functions deploy assistant-understand
```

После публикации проверьте команду из авторизованного кабинета. Без обоих секретов функция намеренно отвечает `not_configured`, а интерфейс продолжает работать на локальном безопасном разборе.

## Границы безопасности

- функция принимает только JWT авторизованного пользователя и повторно проверяет его через Supabase Auth;
- запрос ограничен 24 КБ и 12 обращениями в минуту на пользователя в пределах экземпляра функции;
- телефоны и email маскируются перед обращением к модели;
- в модель передаются только ограниченные названия услуг, имена из нужного диапазона записей, даты, время, роли и агрегаты; телефоны, заметки и платёжные реквизиты не передаются;
- ответ модели обязан соответствовать строгой JSON-схеме и затем повторно проверяется локальным детерминированным движком;
- модель не получает прямого доступа к базе и не выполняет операции. Перенос, отмена и создание по-прежнему проходят через штатную форму и отдельное подтверждение;
- запрос к Responses API использует `store: false`; текст команды не журналируется функцией;
- при тайм-ауте, ошибке провайдера или отсутствии настройки используется локальный разбор.

Перед включением в рабочей среде нужно принять условия обработки данных внешним провайдером, выбрать модель с подходящими стоимостью и доступностью и добавить расход API в мониторинг проекта.
