# Уведомления клиентам в Telegram

После записи клиент нажимает «Получать уведомления в Telegram» и подтверждает доступ в коротком окне Telegram. Переходить в чат и запускать бота не требуется. После подтверждения текущая запись связывается с Telegram ID клиента, а подтверждения, изменения и напоминания отправляются автоматически.

## Переменные функции

Используется уже сохранённый в Supabase `TELEGRAM_BOT_TOKEN`. `SUPABASE_URL` и `SUPABASE_SERVICE_ROLE_KEY` автоматически доступны Edge Function в проекте Supabase.

Миграция `supabase-migration-v77.sql` сама создаёт случайный 256-битный секрет в Supabase Vault. Cron получает исходный секрет только внутри базы, а Edge Function получает через закрытую service-role RPC только его SHA-256-хеш. Секрет не добавляется в браузер, GitHub или исходный код.

## Активация

1. Применить исходные Telegram-миграции и затем `supabase-migration-v77.sql`.
2. В BotFather выполнить `/setdomain` для клиентского бота и указать `aladushka9180-droid.github.io`. Без привязанного домена Telegram Login отклонит авторизацию.
3. Развернуть функцию `telegram-client-notify` без проверки JWT на входе: `/authorize` проверяет HMAC-подпись Telegram и токен записи, а `/reminders` проверяет секрет из Vault.
4. Старый маршрут `/connect` оставлен только для ранее закэшированных страниц. Он продолжает устанавливать webhook на адрес
   `https://cawexmmrqjvothcbgjxr.supabase.co/functions/v1/telegram-client-notify`
   с секретной проверкой запросов.
5. Убедиться, что v77 создала задачу `telegram-client-reminders-hourly` с заголовком `x-reminder-secret`.
6. Опубликовать клиентские файлы одной актуальной версии кэша.

## Проверка

1. Создать тестовую запись на новый номер.
2. На странице успеха нажать «Получать уведомления в Telegram» и разрешить отправку сообщений в окне Telegram.
3. Убедиться, что страница показывает «Уведомления подключены», а в Telegram пришло подтверждение с услугой, датой, временем и ссылкой управления.
4. Перенести запись — должно прийти обновление.
5. Отменить запись — должно прийти уведомление об отмене.
6. Для теста напоминания временно создать запись на интервал 23–25 часов вперёд и дождаться ежечасного запуска.

Секреты нельзя добавлять в `config.js`, Git или код сайта.
