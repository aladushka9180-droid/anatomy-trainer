# Минута — онлайн-запись

Готовая статическая демо-версия онлайн-записи для GitHub Pages. Работает без сервера и устанавливается на телефон как веб-приложение.

Записи сохраняются только в браузере текущего устройства. Для общей базы клиентов и уведомлений потребуется подключить серверную часть.

## Публикация

GitHub Pages: Settings → Pages → Build and deployment → Deploy from a branch → `main` → `/(root)` → Save.
