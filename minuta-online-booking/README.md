# Минута — онлайн-запись

Онлайн-запись для GitHub Pages с общей базой Supabase. Клиенты выбирают услугу и свободное время, а исполнители регистрируются, добавляют свои услуги и управляют заявками в отдельном кабинете.

Доступ к данным ограничен политиками Row Level Security: клиент не может читать чужие записи, исполнитель видит только свои услуги и заявки.

## Надёжность

- Кабинет подписывается на изменения записей через Supabase Realtime и дополнительно сверяется с сервером раз в минуту.
- Последние записи, услуги и расписание сохраняются в IndexedDB и доступны исполнителю для чтения при временной потере связи.
- Страница клиента показывает, проверена ли возможность записи, и не выдаёт сетевую ошибку за успешно созданную заявку.
- Клиент может скопировать персональную ссылку управления записью сразу после подтверждения.
- Service Worker использует единый номер сборки и не подменяет отсутствующие JavaScript-файлы HTML-страницей.

Проверка перед публикацией:

```bash
node minuta-online-booking/smoke-test.mjs
```

## Публикация

GitHub Pages: Settings → Pages → Build and deployment → Deploy from a branch → `main` → `/(root)` → Save.
