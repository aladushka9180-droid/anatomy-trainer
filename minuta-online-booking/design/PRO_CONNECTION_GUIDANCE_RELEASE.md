# Плашка связи PrimeTime Pro — контрольная точка

- Владелец реализации и будущего выпуска: задача «Гибкое время офлайн-записи — Pro и клиент»; ветка `codex/pro-connection-guidance-20260927`.
- Статус: отдельный непубликуемый кандидат. `provider-connection-guidance.js` формирует честный текст для офлайна, отказа сервера, неподтверждённого сеанса и восстановления. Счётчик результата принимает только явно подтверждённые сервером ID исходной очереди и сбрасывается при смене аккаунта. `provider-connection-guidance.css` подготовлен для компактной плашки.
- Проверено: 5/5 целевых тестов состояния и согласования чисел; синтетический экран 390/760/1440 без переполнения, раскрытие помощи, серверный отказ, итог и скрытие при обычном online. Реальные записи, сообщения, SQL и склад не менялись. Живой экран и установленная Android PWA не проверены для этого кандидата.
- Зависимость: владелец UI-аудита завершает свой выпуск и общую CI. После этого взять свежий `origin/main`, встроить плашку в `provider.html` и существующую синхронизацию `provider.js`, связать CSS/JS/SW с новой версией кэша. Текущие общие файлы не правились параллельно.
- Приёмка: без пригодного снимка не обещать создание; при `online=true` и отказе транспорта не писать «Нет интернета»; 401/403 и истёкший сеанс оставлять отдельным состоянием; блокировать одновременные ручные повторы; после восстановления показывать один фактический сводный результат и переход в существующий журнал/очередь. Подтверждать запись лишь после ответа сервера и обработки элемента очереди. Затем целевые тесты, браузер 390/760/1440, CI/Pages, живые байты и безопасный клик на рабочем экране.
