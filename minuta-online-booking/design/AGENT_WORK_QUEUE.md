# Очередь исполнителей Minuta

Оперативная передача работы, а не доказательство актуального состояния сервера.
Перед продолжением подтвердить живые статусы агентов, Git и владельцев файлов.

## Правило продолжения

Всего до четырёх исполнителей: координатор и три агента. Агент отправляет
checkpoint с результатом, файлами и проверками и сразу берёт следующий заранее
назначенный пункт. На последнем пункте заранее сообщает координатору, чтобы
получить новую ограниченную очередь. Блокер одного пункта не блокирует другие
независимые согласованные задачи. Не создавать работу только ради занятости.

Только один автор каждого файла; другой исполнитель может проверять его
read-only. Исправления после проверки вносит автор либо новый явно назначенный
владелец после передачи. Агенты не переключают ветки, не делают commit/push
и не публикуют самостоятельно. Координатор проверяет и интегрирует точные файлы.

## Возобновление

Настроено автоматическое продолжение этой задачи раз в 10 минут.
Это страховка между запусками; внутри активного запуска переход по очереди
происходит сразу после checkpoint, без ожидания таймера.
Сначала проверять существующих агентов, не создавать дубли. При отсутствии
безопасной полезной работы ждать зависимости; если требуется решение пользователя,
запрашивать его. Завершить автоматическое продолжение после выполнения
согласованных критериев дорожной карты.
