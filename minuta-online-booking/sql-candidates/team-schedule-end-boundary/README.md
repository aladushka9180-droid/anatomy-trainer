# Граница окончания смены

SOURCE-кандидат; не применяется к production автоматически и пока не получает номер миграции. Выпускает только ROOT после защищённой копии, полноценного isolated restore и apply/read/rollback/reapply.

`apply.sql` заменяет два сравнения времени на сравнения даты и времени: в `minuta_booking_fits_active_shift` и предварительной проверке `set_minuta_branch_shifts_enabled`. Смена 10:00–23:00 больше не покрывает запись 22:30 длительностью 120 минут. Запись, заканчивающаяся ровно в 23:00, разрешена; перерывы, отсутствия и отключённый строгий режим сохраняют прежний контракт.

Пакет меняет текущие определения функций через `pg_get_functiondef` с проверкой единственного ожидаемого выражения. Подписи, владелец, ACL, SECURITY DEFINER, search_path и окружающий код сохраняются. Повторный запуск допускает только точное уже применённое изменение; неизвестный исходник останавливает всю транзакцию. `rollback.sql` выполняет обратную замену с теми же проверками.

O08 отдельно изменяет включение строгих смен. Перед интеграцией сверить оба определения с окончательной O08-версией: этот пакет не заменяет функцию целиком и не разрешает потерять её новые проверки. Если выражения отличаются, пересобрать и заново проверить пакет на точной итоговой схеме.

Проверка: `node minuta-online-booking/tests/team-schedule-end-boundary-test.mjs` с установленным `@electric-sql/pglite` (можно задать `MINUTA_PGLITE_MODULE`). Частичная вымышленная схема подтверждает регрессию и сохранение контрактов, но не полноценное восстановление, production-приёмку или все клиентские пути создания записи.
