# Уведомления: кандидат мягкого минимализма

## Цель
Внедрить утверждённый макет уведомлений Eldion Pro: плоские поверхности выбранной темы, два столбца на широком экране, компактные списки, заметные ошибки, сворачиваемый технический журнал и ручной выбор Telegram/WhatsApp.

## Сделано
- Новые изолированные CSS/JS загружаются через существующий механизм optional assets. В provider.js добавлен только фактический pending count для сводки.
- Сохранены исходные элементы и обработчики событий, отметок, повторов, шаблонов, каналов, настроек и посетителей.
- Выбор мессенджера меняет только ссылку ручного открытия. Телефон и точный текст берутся из существующей проверенной WhatsApp-ссылки; Telegram использует официальную форму phone-number link. Выбор не отправляет сообщение и не изменяет настройки автоматической доставки. Получателя и отправку подтверждает пользователь в приложении.
- Выбор для задачи сохраняется при перерисовке в пределах текущей страницы. Отметка отправки остаётся отдельным действием.
- Важные события: первые три в каждой датированной группе; ручные сообщения: первые четыре; ошибки: первые две. Остальные доступны по кнопке раскрытия. Все настройки событий и каналов доступны на прежних вкладках.
- Обычные статусы перемещены в журнал без изменения семантики; число ожидающих автоматической отправки видно на закрытом журнале. Ошибки остаются снаружи. При перегруппировке Chrome мог оставлять content-visibility:auto строки пустыми; для коротких списков уведомлений используются видимые строки.

## Зафиксированные решения
Автоматические каналы, согласия и доступность шлюзов определяет прежний серверный controller. Ручной Telegram link не доказывает подключение автоматического Telegram и не подтверждает доставку. Нет новых миграций, RPC или серверных изменений.
