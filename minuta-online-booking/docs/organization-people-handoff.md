# Люди и филиалы — мягкий минимализм

## Область
Согласованный макет перенесён в существующие DOM, формы и organization RPC.
Карточки спокойнее, иконки из ui-icons.svg, счётчики возле заголовков,
добавление и приглашение в шапках. Формы раскрываются по запросу.
Сайдбар, навигация групп, ресурсы, услуги, график, склад и темы не переделаны.
Код без SQL, внешних библиотек, новых прав и изменения рабочих данных.

## Подключение владельцем выпуска
Исполнитель изменяет organization.js и собственные organization-people.js/.css,
fixture/browser-test, этот документ и отдельный workflow. Общие файлы остаются
у ROOT. Перед объединением PR требуется подключить:
1. В provider.html: organization-people.js с defer непосредственно перед
   organization.js; organization-people.css после остальных stylesheet.
2. В sw.js: оба новых ресурса в OPTIONAL_ASSETS; organization.js — прежний
   обязательный ресурс. Согласовать его новую версию в HTML и ASSETS.
3. Общие cache/site-update/provider версии назначает ROOT на свежем main.
   Бюджет основного precache не расширять; новые UI-ресурсы optional.
4. На итоговом дереве запустить people-browser, полный provider integration,
   timezone summary, controller, redirect, startup и обязательный CI/Pages.
   Fixture всегда читает файлы собственного checkout, запросы наружу запрещены.

## Данные и семантика
- Счётчики содержат только активные филиалы/участников. Приглашения отдельно.
- Доступ, приём клиентов и public_booking_enabled — разные состояния.
- Филиалы сотрудника и сотрудники филиала берутся из сохранённых активных
  смен за ближайшие 14 календарных дней Europe/Samara с учётом отсутствий.
  В карточке указан период. Это график, а не постоянное назначение и не
  обещание свободного слота. Постоянных назначений новый API не создаёт.
- get_minuta_shift_workspace — только чтение, правильный organization_id
  и полные массивы обязательны. Ошибка/timeout/чужой scope дают неизвестное
  состояние и повторную проверку. Специалисту чужой график не объявляется
  пустым или проверенным; для филиала обозначается ограниченный обзор.
- Последний действующий владелец защищён в интерфейсе, ожидающее приглашение
  владельца не считается членством. Серверные проверки сохранены.
  Основной филиал остаётся активным по прежнему контракту.

## Формы и сохранение
Черновики в sessionStorage, привязаны к actor/org, срок 24 часа, очищаются при
organization reset/logout. Никаких токенов. В другой организации поля сбрасываются,
после возвращения восстанавливаются соответствующие черновики; запретные роли
и disabled поля из черновика не восстанавливаются. Закрытие сохраняет черновик,
«Отменить изменения» явно его удаляет. На 390/760 открыта одна форма.
При переключении форм предыдущая закрывается до фокусировки и мгновенной
прокрутки к полю: изменение высоты не оставляет кнопку под навигацией.
Функциональный сценарий проверяется с обычной анимацией и кликами без force.

Общая блокировка повторной отправки, busy кнопки и отмена/переключатель.
Подтверждённый отказ не стирает ввод. Неопределённый ответ/сетевая ошибка
блокирует повторный write до успешного обновления workspace: сервер мог
успеть выполнить запрос. Подтверждённый ответ обновляет список/счётчики/журнал
и aria-live. Ввод, изменённый во время запроса, остаётся следующим черновиком.

## Проверка и границы доказательства
Проверки используют полный текущий provider DOM, CSS, реальные контроллеры
и select. Transport/session только синтетические, реальные приглашения,
права, записи и настройки не меняются. Контрольные ширины 390/760/1440,
темы Pink Porcelain, Celadon, OLED Mono. Локальная функциональная проверка
не является подтверждением production write или установленного Android PWA.

Сайт пока не обновлён этим кандидатом. Приёмка в целевой среде: 0 из 6;
остались оформление/данные/формы/проверка конечного дерева/выпуск/live.
