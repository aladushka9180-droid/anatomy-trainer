# Статистика: передача кандидата владельцу выпуска

Область: пять критериев из `statistics-clarity-acceptance.md`. Целевая среда — опубликованный кабинет PrimeTime Pro. До интеграции и проверки рабочего URL выполнено 0 из 5; осталось 5. Локальный интерфейс и сценарии проверяются на изолированных данных, без Auth, рабочих записей, платежей и service worker.

## Изменения

Стоимость услуг, полнота оплаты и список визитов используют одну выборку с теми же датами, организацией и сотрудником. Импортированная история входит в стоимость; неизвестная оплата не становится долгом. Денежные показатели и сравнение берутся из полного журнала операций. Незавершённый месяц сравнивается с теми же днями прошлого месяца; нулевая база не получает процент.

На первом экране три главные суммы, компактные аренда и товары, единые контурные иконки, короткий статус полноты. Визиты, загрузка и цели раскрываются одним блоком. При отключении финансового модуля исходные блоки возвращаются на свои места. Прибыль не подменяется денежным результатом. Ошибка источника сохраняет выбранную область в детализации.

## Обязательная интеграция

`provider.js` принадлежит владельцу общего кабинета и в этой ветке не изменён. До выпуска применить два подключения из `statistics-clarity-provider.patch`: справочник сотрудников для подписи и фильтра. Проверка `node minuta-online-booking/tests/statistics-clarity-provider-patch.mjs --check` проверяет применимость; `--write` только обновляет файл патча, приложение не изменяет. Новые сценарии сотрудника и браузерная проверка исполняют эти два подключения поверх текущего исходника. Их PASS не подтверждает подключение в опубликованном приложении.

Кандидат требует атомарного повышения версии HTML, JS, CSS и SW обычным владельцем выпуска. Этот пакет не меняет версию, production SQL, правила доступа или финансовые операции. PR должен оставаться draft до подключения двух точек в общем файле и приёмки владельцем.

## Проверка

Новые проверки: общая выборка визитов, неизвестная цена, устаревший период/актёр/организация; сохранение сотрудника в месяце, за всё время и при сбое справочника; браузерные сценарии на 376/390/760/1440. Сохранены существующие проверки финансовых сценариев, полного периода и распространения фильтров. Снимки CI доступны в артефакте `statistics-clarity`.

Перед окончательной приёмкой: свежая основная ветка и совместимость с изменениями владельца; общие обязательные проверки; публикация; реально загруженные ресурсы нового выпуска и безопасные клики на рабочем URL. Отдельно подтвердить сервисную стоимость 5 800 ₽ в октябре, соответствие предупреждения списку и сохранение сотрудника после «Всё время» и обновления организации. Физический Android этой проверкой не подтверждается.
