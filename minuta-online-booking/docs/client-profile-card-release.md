# Компактная карточка клиента — пакет для владельца выпуска

Область: согласованный пользователем макет профиля, существующие ободки и точный счётчик. Зависит от пакета ободков `a71dca09` (или его интегрированной копии). Новые файлы не меняют данные, условия награды, оплату и права. Рабочий кабинет не использовать для тестовых изменений.

Общие `provider.html`, `provider.js`, `sw.js` оставлены владельцу текущего выпуска. После завершения предыдущего выпуска интегрировать новые JS/CSS и два тестовых файла, затем подключить:

1. В `provider.html` после последнего stylesheet добавить `<link rel="stylesheet" href="client-profile-card.css?v=1">`. Перед `provider.js` добавить `<script src="client-profile-card.js?v=1" defer></script>`.
2. В конце `renderClientDetail`, после `if (clientChanged) activateClientProfileJump(...)`, добавить:

```js
  window.PrimeTimeClientProfileCard?.render({client,visits,
    scope:`${currentUser?.id || ''}:${activeClientOrganizationId || ''}`,
    outcome:bookingOutcome,status:bookingStatus,value:bookingCalculatedValue,money,serviceName});
```

3. В `OPTIONAL_ASSETS` service worker добавить `./client-profile-card.css?v=1` и `./client-profile-card.js?v=1`. Назначить свежий согласованный номер PWA, обновить ссылку provider.js и проверить startup budget: новая логика вынесена в optional, ядро растёт только на вызов.
4. Проверить интегрированную версию: новый `tests/client-profile-card-browser-test.mjs`, существующие счётчик/ободки, возврат из карточки записи, программа наград, smoke/startup и обязательный PWA переход. Затем CI/Pages и опубликованные ресурсы/доступный безопасный сценарий.

Локально проверены: 4 темы (Pink Porcelain, Sage, Noir Rose, Midnight) × 390/760/1440; все 14 порогов; свободная область фото; сохранность исходных кнопок; настоящий переключатель вкладок из provider.js; предстоящие/прошлые записи, долг/импорт/неявки/отмены; пагинация, пустая история и телефон, повторный render. Снимки светлой мобильной и тёмной настольной карточки просмотрены. Окно уровней открыто кликом во встроенном браузере.

Визуальная оценка кандидата: ясность 9, главное действие 9, иерархия 9, компактность 8, соответствие теме 9. Ограничение: заполненная живая карточка и установленный Android не проверены — разрешённый кабинет пустой, рабочий кабинет трогать запрещено. Локальный сценарий полностью синтетический, сеть ограничена localhost. Это кандидат, не подтверждение публикации.
