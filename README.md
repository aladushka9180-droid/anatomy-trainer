# Анатомия — умный тренажёр

Это готовый статический сайт для GitHub Pages.

Файлы index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png и .nojekyll
должны лежать В КОРНЕ репозитория.

GitHub Pages:
Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save.

## Анатомические иллюстрации

В тренажёре используются шесть иллюстраций из *Gray's Anatomy* (1918), находящихся в общественном достоянии. Источник каждой иллюстрации указан прямо под изображением и ведёт на страницу файла в Wikimedia Commons.

## Раздел костей

Кости и позвонки вынесены в отдельный режим и не смешиваются с вопросами по мышцам. В нём изучаются 35 костей и типов позвонков: расположение, сочленения и отличительные ориентиры. Добавлены пять свободно распространяемых иллюстраций Wikimedia Commons.

## Язык вопросов

Переключатель «Учебный / Простой» меняет только формулировки и число вариантов ответа, не сбрасывая прогресс. В простом режиме сложные термины расшифровываются прямо в тексте и показываются три похожих ответа вместо четырёх. В учебном режиме сохраняются анатомические формулировки. Кнопка «Объяснить вопрос проще» позволяет упростить только текущий вопрос. После ошибки выводятся правильный ответ, простое объяснение и ассоциация для запоминания.

## Голосовой помощник

Помощник умеет читать вопрос и варианты ответа, принимать голосовые ответы и выполнять команды «повтори», «подсказка», «объясни проще», «дальше» и «в меню». Доступны сохраняемые настройки выбранного голоса, автоозвучки, режима без рук и скорости речи. Список заполняется русскими голосами, установленными на текущем телефоне или компьютере; выбранный вариант можно заранее прослушать. После ответа помощник может озвучить результат, объяснение и ассоциацию для запоминания. Если браузер не поддерживает синтез или распознавание речи, обычные кнопки тренажёра продолжают работать.

## Оформление

В отдельном экране настроек доступны системная, тёмная, светлая, минималистичная, атласная и цветная темы. Палитра содержит 18 точных оттенков по всему цветовому кругу и ползунок для собственного цвета. Можно отдельно выбрать один из четырёх заметно отличающихся шрифтов, размер текста, плавные анимации и повышенный контраст. Настройки сохраняются только на устройстве и не влияют на вопросы, прогресс или озвучку.

## Справочник и помощник

Справочник собирает материалы тренажёра в единый поиск по мышцам, костям, движениям, пальпации, безопасности и терминам. Встроенный помощник объясняет найденные сведения простыми словами, предлагает ассоциации для запоминания и отдельно предупреждает о возможных красных флагах. Локальный режим работает без интернета. Для будущего нейросетевого режима подготовлен безопасный серверный контракт; API-ключ никогда не помещается в браузерный код.

В подсказке есть второй уровень «Показать ещё понятнее». После любого ответа — правильного или ошибочного — доступна кнопка «Узнать подробнее»: она показывает ещё более простое объяснение, ассоциацию, подходящую анатомическую схему, ссылку на русскоязычные видео по текущей теме и переход к помощнику.

## Анатомия для массажистов

Третья самостоятельная вкладка содержит 64 практических вопроса по пальпаторной анатомии, топографии, кинезиологии, областям тела и безопасности массажиста. После ответа показываются простое объяснение, правило для запоминания и, где необходимо, отдельное предупреждение о безопасной работе. Ситуационные задания обучают прекращать процедуру при красных флагах, соблюдать согласие и границы компетенции; модуль не предназначен для постановки диагноза и не заменяет очное обучение.

## Озвучка

Доступны системная озвучка и режим без озвучки. Можно выбрать один из русских голосов, установленных на текущем телефоне или компьютере, настроить скорость речи, включить автоозвучку и голосовые ответы без рук.

### Локальная предгенерация OpenAI TTS

Короткие образцы голосов `marin`, `cedar`, `coral`, `sage` и `onyx` создаются локальным скриптом. Он использует только `OPENAI_API_KEY` из переменной окружения или корневого файла `.env.local`; значение ключа никогда не выводится и не записывается в манифест либо аудиофайлы.

`.env.local` предназначен только для локальной машины. Его нельзя загружать в GitHub, добавлять в архив сайта или копировать в `assets`. Перед публикацией убедитесь, что файл исключён из загрузки и не отслеживается Git.

Сначала выполните оценку без API-запросов:

```powershell
node scripts/generate-openai-tts.mjs
```

После проверки количества запросов можно создать пять коротких образцов:

```powershell
node scripts/generate-openai-tts.mjs --generate --max-calls=5
```

Для двух выбранных голосов:

```powershell
node scripts/generate-openai-tts.mjs --generate --voices=marin,cedar --max-calls=2
```

Скрипт не выполняет массовую генерацию молча: реальный запуск требует флага `--generate`, а число запросов ограничивается `--max-calls`. Результаты сохраняются в `assets/audio/samples`, а `assets/audio/manifest.json` содержит только публичные метаданные, пути, размеры и SHA-256 аудиофайлов. Для точных ударений отображаемый `displayText` отделён от служебного `speechText`, где можно использовать `ё` и знак ударения.

Пока клипы не созданы, манифест имеет `generationStatus: "pending"` и пустой массив `clips`. После успешной генерации скрипт заменит его фактическими метаданными и датой создания. Если API сообщает об отсутствии кредитов, пополните баланс проекта OpenAI и повторите ту же команду; новый ключ сам по себе не добавляет кредиты.
