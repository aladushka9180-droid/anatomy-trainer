# Анатомия — умный тренажёр

Это готовый статический сайт для GitHub Pages.

Файлы index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png и .nojekyll
должны лежать В КОРНЕ репозитория.

GitHub Pages:
Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save.

## Анатомические иллюстрации

В тренажёре используются шесть иллюстраций из *Gray's Anatomy* (1918), находящихся в общественном достоянии. Источник каждой иллюстрации указан прямо под изображением и ведёт на страницу файла в Wikimedia Commons.

## Раздел костей

Кости и позвонки вынесены в отдельный режим и не смешиваются с вопросами по мышцам. В нём изучаются 35 костей и типов позвонков: расположение, сочленения и отличительные ориентиры. Добавлены пять свободно распространяемых иллюстраций Wikimedia Commons.

## Язык вопросов

Переключатель «Учебный / Простой» меняет только формулировки и число вариантов ответа, не сбрасывая прогресс. В простом режиме сложные термины расшифровываются прямо в тексте и показываются три похожих ответа вместо четырёх. В учебном режиме сохраняются анатомические формулировки. Кнопка «Объяснить вопрос проще» позволяет упростить только текущий вопрос. После ошибки выводятся правильный ответ, простое объяснение и ассоциация для запоминания.

## Голосовой помощник

Помощник умеет читать вопрос и варианты ответа, принимать голосовые ответы и выполнять команды «повтори», «подсказка», «объясни проще», «дальше» и «в меню». Доступны сохраняемые настройки выбранного голоса, автоозвучки, режима без рук и скорости речи. Список заполняется русскими голосами, установленными на текущем телефоне или компьютере; выбранный вариант можно заранее прослушать. После ответа помощник может озвучить результат, объяснение и ассоциацию для запоминания. Если браузер не поддерживает синтез или распознавание речи, обычные кнопки тренажёра продолжают работать.

## Оформление

В раскрывающемся разделе «Настройки оформления» доступны системная, тёмная, светлая, минималистичная, атласная и яркая темы. Можно отдельно выбрать один из пяти безопасных системных шрифтов, размер текста, цвет акцента, плавные анимации и повышенный контраст. Настройки сохраняются только на устройстве и не влияют на вопросы, прогресс или голосового помощника. Кнопка «Вернуть стандартный вид» восстанавливает системную тему и обычный размер текста.

## Анатомия для массажистов

Третья самостоятельная вкладка содержит 64 практических вопроса по пальпаторной анатомии, топографии, кинезиологии, областям тела и безопасности массажиста. После ответа показываются простое объяснение, правило для запоминания и, где необходимо, отдельное предупреждение о безопасной работе. Ситуационные задания обучают прекращать процедуру при красных флагах, соблюдать согласие и границы компетенции; модуль не предназначен для постановки диагноза и не заменяет очное обучение.

## Человеческая озвучка

Помимо системного синтеза доступны режимы «Человеческая запись» и «Без озвучки». В режиме человеческой записи пользователь может отдельно записать текущий вопрос и объяснение после ответа через микрофон. Записи хранятся в IndexedDB на устройстве, воспроизводятся вместо синтезированного голоса и могут быть экспортированы в один JSON-пакет для резервной копии или переноса в другой браузер. Для незаписанных вопросов можно включить необязательный системный запасной голос.
